# Obsidian for iPhone

Нативная iPhone-версия браузера с чёрным стеклянным интерфейсом, отдельной иконкой, вкладками, поиском, закладками, историей, фонами из Фото и значками сайтов. Сайты отображает системный WKWebView. Минимальная версия — iOS 17.

## Сборка через GitHub

1. Разместите содержимое этой папки в корне репозитория GitHub.
2. Откройте Actions → Build Obsidian for iPhone.
3. Сборка запускается при загрузке исходников; при необходимости используйте Run workflow.
4. После успешной сборки откройте Releases: там появятся `Obsidian-unsigned.ipa` и снимок iPhone Simulator.

IPA создаётся только после компиляции настоящего ARM64-приложения. Скрипт проверяет Mach-O, платформу iPhoneOS, ресурсы и целостность архива. Переименование исходников в `.ipa` не используется.

## Установка

`Obsidian-unsigned.ipa` не подписан. Для установки на iPhone требуется подпись приложения подходящим сертификатом и профилем. Учётные данные Apple в проект и репозиторий не добавляются. Можно также открыть `Obsidian.xcodeproj` на Mac, выбрать свою команду в Signing & Capabilities и установить приложение через Xcode.

Для публикации через TestFlight или App Store потребуются соответствующая учётная запись разработчика и отдельная настройка распространения. У приложения нет настроенного права быть браузером по умолчанию.

## Данные

Закладки и история сохраняются в контейнере приложения. Фоновое изображение обрабатывается до размера 2048 пикселей, хранится локально и не отправляется на сервер. Сайты загружаются напрямую; их обычные сетевые запросы, cookies и хранение данных обрабатывает WKWebView. Иконки быстрого доступа загружаются напрямую с соответствующих сайтов.

## Состояние проверки

Локально на Windows доступны только проверки структуры проекта и ресурсов. Компиляция, запуск, снимок экрана и UI-проверка поиска и вкладок выполняются заданием GitHub Actions на macOS. Успешная сборка и запуск в Simulator не подтверждают вход на все сайты, воспроизведение видео и работу на физическом iPhone. Вкладки пока не восстанавливаются после полного перезапуска; расширения Firefox и синхронизация профиля Windows не реализованы.
